# Tarea #1 Programación II



Descripción

Este proyecto consiste en un sistema de gestión desarrollado en Java utilizando NetBeans. El objetivo principal es ofrecer una solución funcional y organizada para la administración de datos, cumpliendo con los estándares solicitados en las asignaciones del curso.

**Cómo ejecutar el proyecto**



Descarga: Haz clic en el botón verde "Code" en GitHub y selecciona "Download ZIP".



Abrir: Abre NetBeans y selecciona File > Open Project, buscando la carpeta donde extrajiste el archivo.



Ejecutar: Una vez cargado, abre la clase principal y presiona Shift + F6 para iniciar el programa.
